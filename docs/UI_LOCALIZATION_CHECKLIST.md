# UI日本語ローカライズ チェックリスト

## セットアップ

### 1. 環境準備
```bash
# 依存パッケージのインストール
yarn install

# ビルド
yarn build
```

### 2. サーバー起動（ターミナル1）
```bash
yarn start:backend
# ポート3001で起動
```

### 3. フロントエンド起動（ターミナル2）
```bash
yarn start:frontend
# ポート5173で起動
```

### 4. Cloudflare Tunnel起動（ターミナル3）
```bash
# 初回のみセットアップ
./scripts/setupCloudflaredTunnel.sh

# Tunnelを起動
./scripts/runCloudflaredTunnel.sh
```

### 5. ブラウザアクセス
- ローカル: http://localhost:5173
- Cloudflare Tunnel: `https://<TUNNEL_ID>.trycloudflare.com`

## トラブルシューティング

### 日本語が表示されない場合
1. ブラウザキャッシュをクリア（Cmd+Shift+Delete）
2. 言語セレクターで日本語を再選択
3. ページをリロード（Cmd+R）
4. コンソール（F12）でエラーを確認

### 一部テキストが未翻訳の場合
1. `frontend/src/locales/ja.json`を確認
2. 翻訳キーが正しくマップされているか確認
3. 該当するキーを追加・修正

### 言語セレクターが表示されない場合
1. `frontend/src/components/LanguageSelector/LanguageSelector.tsx`を確認
2. i18nextの初期化を確認
3. `LANG`環境変数の設定を確認

## Cloudflare Tunnel関連

### トンネルの確認
```bash
cloudflared tunnel list
```

### トンネルの削除
```bash
cloudflared tunnel delete vera-local-tunnel
```

### ログの確認
```bash
cloudflared tunnel run vera-local-tunnel --loglevel=debug
```

### 複数ホストの設定
- `~/.cloudflared/config.yml`を編集して、`ingress`ルールを追加
- 詳細は`docs/CLOUDFLARE_TUNNEL_SETUP.md`を参照
